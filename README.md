# KVL Khyati Portfolio

Premium retro-pixel and futuristic portfolio website built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Lenis, React Icons, and reusable shadcn-style UI primitives.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`

## Contact Form

Create `.env.local` from `.env.example` and add a Resend API key.

Resend's default `onboarding@resend.dev` sender only sends test emails to the Resend account owner. To send contact messages to `khyatikvl@gmail.com`, verify a domain in Resend and set `RESEND_FROM_EMAIL` to an address on that verified domain.
